# Contributing

Thank you for considering contributing to this project! This document will guide you through the contribution process.

## Code of Conduct

Please review our [Code of Conduct](CODE_OF_CONDUCT.md) to understand the community standards for interaction.

## Getting Started

1. **Fork the repository** — Create your own fork of the project on GitHub
2. **Clone your fork** — Clone the forked repository to your local machine
3. **Create a branch** — Create a new branch for your work: `git checkout -b feature/your-feature-name`
4. **Make your changes** — Implement your changes with clear, descriptive commits
5. **Test your changes** — Ensure all tests pass and your code follows project conventions
6. **Push to your fork** — Push your changes to your forked repository
7. **Submit a pull request** — Open a pull request against the main repository's main branch

## Contribution Guidelines

- **Commit messages** — Write clear, concise commit messages that describe the purpose of each commit
- **Pull request descriptions** — Provide detailed descriptions of what your PR accomplishes and why
- **Code quality** — Ensure your code follows existing project conventions and best practices
- **Tests** — Add or update tests as needed to cover your changes
- **Documentation** — Update documentation to reflect any changes to functionality

## Reporting Issues

If you discover a bug or have a feature request:

1. **Check existing issues** — Search the issue tracker to see if your issue has already been reported
2. **Create a new issue** — If your issue hasn't been reported, create a new issue with a clear description
3. **Include details** — Provide as much context as possible, including steps to reproduce bugs

## Questions?

If you have questions about contributing, please open an issue or reach out to the project maintainers.

Thank you for your contributions!
